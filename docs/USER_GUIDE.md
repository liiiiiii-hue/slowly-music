# Slowly Music 使用说明书

## 1. 连接私人网盘

1. 进入「设置 → WebDAV 连接」。
2. 填写提供商给出的 HTTPS WebDAV 地址、账号、应用密码。不要把普通网页登录地址当作 WebDAV 地址。
3. 测试并连接。建议使用网盘专用应用密码。
4. 可开启「记住连接」；连接凭证经 Android Keystore 加密保存在本机。关闭时仅用于当前进程。「断开并忘记连接」清除本机保存项。

应用不内置存储服务，需要自己准备支持 WebDAV 的网盘或服务器。

## 2. 建立音乐库

在「设置 → 音乐库管理」选择音乐目录与统一歌词目录，重新扫描。音乐目录递归扫描 MP3。歌曲信息优先来自文件标签；建议预先填写标题、歌手、专辑并嵌入封面。

音乐库支持搜索。歌曲右侧加入按钮可把歌曲加入一个或多个歌单。歌单支持命名、选择本机图片作封面、删除及移除单曲。

## 3. 播放、队列和定位

点击歌曲进入播放页；点击收起图标返回。底部播放栏可打开当前播放页或暂停/继续。

当前歌曲使用主题选中底色和标题色；行内播放/暂停图标与底栏使用同一播放状态。暂停后仍保留选中状态。音乐库、歌单详情及播放队列的悬浮音符按钮可滚动到当前歌曲；若当前歌曲不在该歌单中，不显示定位按钮。音乐库定位时会清除搜索条件以显示目标。

播放页支持顺序、随机和单曲循环。拖动进度条时预览目标位置，松手后提交跳转；网络缓冲可能造成实际声音延迟。队列按钮查看当前队列。

## 4. 封面与歌词

右上切换封面/歌词视图；设置中调整歌词字号和模糊背景。歌词字体跟随系统。LRC 文件应包含时间戳，并与音频录音版本一致；无时间轴的歌词不能自动同步。

外部 LRC 优先，失败后回退部分内嵌歌词。同名冲突可手动指定。支持标准及增强 LRC；内嵌读取覆盖部分 ID3v2.3/2.4 毫秒 SYLT 和含 LRC 时间戳的 USLT，存在读取大小限制，不代表支持所有标签变体。USLT 本身不是同步歌词标准。

## 5. QQ 音乐

1. 手机上安装并登录 QQ 音乐，在 QQ 中开始播放歌曲。
2. 从 Slowly 底部导航进入「QQ 音乐」。
3. 若提示连接，进入系统通知访问设置，允许 Slowly Music 的联动服务，再返回。
4. 使用播放/暂停、上一首、下一首；标题右侧音乐图标打开 QQ。
5. 封面和歌词由 QQ 媒体会话提供，未提供时显示空状态。若有 LRC 时间轴则高亮当前行，否则显示收到的文本。

QQ 模块沿用 QQ 自己的队列，不会读取收藏，也不能从 Slowly 任意指定在线歌曲。开通 QQ 会员不会自动增加此项目的接口能力。

## 6. 主题与缓存

「设置 → 外观主题」提供五种浅色主题，覆盖导航、播放页、选中态和按钮。模糊背景需要开启且当前歌曲有封面。

「设置 → 缓存管理」查看使用量和清理缓存。上限为 5×1024³ 字节，约 5 GiB；界面标为 5GB。达到上限后淘汰最近最少使用的音频。清理不删除云盘原文件、歌单或歌词索引。

## 7. 常见问题

- **无法连接**：核对 WebDAV 地址、HTTPS、应用密码及提供商限制。
- **没有歌曲**：确认选择了音乐目录并重新扫描，当前以 MP3 为主。
- **无封面**：检查 MP3 内是否确实包含图片，而非电脑播放器缓存。
- **歌词不同步**：确认 LRC 对应同一录音版本及时间戳。
- **QQ 控制无响应**：确认通知访问权限、QQ 已开始播放、系统允许后台运行。QQ 暂未声明支持的控制不会发送。
- **QQ 歌词缺失**：QQ 可能未提供歌词字段；这不代表 QQ 自己的页面没有歌词。
- **模糊背景不显示**：开启播放背景，确认封面存在；记录应用、QQ 和系统版本反馈。
- **后台停止**：完整前台播放服务尚未完成，系统可能回收进程。

反馈问题时请提供应用版本、系统/QQ版本、操作步骤和脱敏截图；不要提交网盘密码、授权头、登录令牌或私人歌词全文。
