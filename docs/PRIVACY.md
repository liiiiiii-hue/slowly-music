# 隐私与权限

本项目没有开发者运营的登录服务器或遥测上传接口。播放私人网盘时，会向用户配置的 WebDAV 服务发送认证信息并请求目录、标签、歌词和音频。

可选保存连接时使用 Android Keystore 加密；音乐库、歌单、歌词索引、图片与音频缓存保存在设备本机。Android allowBackup=false。请注意卸载或清除应用数据可能丢失本机歌单与设置。

QQ 联动需要系统通知访问权限。该权限的系统能力范围较广；当前代码的 NotificationListenerService 不解析通知正文，只通过 MediaSessionManager 查询 QQ 包名的活动媒体会话，读取其公开元数据并发送播放控制。封面、歌词只用于展示；不会自动上传给开发者。

封面选择使用 Android 系统文件选择器；联网权限用于 WebDAV。QQ自己的联网和隐私处理遵循QQ音乐的政策。开源仓库不包含个人账号、凭证、歌单或媒体。

如果发现安全问题，请勿在公开 Issue 中粘贴真实密钥；先用脱敏描述联系仓库维护者。
